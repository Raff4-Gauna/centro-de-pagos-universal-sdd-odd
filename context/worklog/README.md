# Worklog (Carril O / ODD)

Una entrada por cambio chico o spike: `YYYY-MM-DD-slug.md`, con la plantilla `specs/_templates/worklog-entry.md`.
Se crea **antes** de empezar. Si el cambio escala a zona roja o a más de ~5 archivos / ~150 líneas, se frena y se pasa a Carril S.
Los spikes (O2) viven también en `specs/00-platform/spikes/` cuando alimentan una spec.
